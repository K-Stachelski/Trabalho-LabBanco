# Trabalho
Este é um trabalho acadêmico desenvolvido na disciplina de Laboratório de Banco de Dados, que tem como objetivo projetar e implementar um banco de dados para um jogo de fantasia, contemplando a organização, o armazenamento e o gerenciamento das informações necessárias para o funcionamento do jogo.
